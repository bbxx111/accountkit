# v1.0.0

状态：已发布（2026-10-31）。v1.0.0 是 accountkit 的第一个正式版本，模块为 `github.com/bbxx111/accountkit`。[GitHub Release](https://github.com/bbxx111/accountkit/releases/tag/v1.0.0) 已发布，两个独立远端消费模块验证通过。正式 tag 固定候选提交 `e1b93da7d050bce6e94766412a81f5c11d994b1f`，annotated tag 对象为 `f497dec1dd487f18cb52e5ee3df85f438bde1831`；[对应 CI](https://github.com/bbxx111/accountkit/actions/runs/41160615369) 全部通过。本段为发布后补记，正式 tag 保持原对象和候选内容不动。

## 运行要求与交付形式

- Go 1.26.5；PostgreSQL 17 与 Redis。源码为单一 Go module，支持 `GOWORK=off`，不依赖外部工作区或本地 replace。
- 嵌入式 Go 库提供根 `accountkit` 门面及独立消费者/管理员 HTTP handler，不监听端口。宿主负责连接池、Redis、发送器、可信代理/IP、请求 ID、管理员身份验证及业务匿名化回调。
- 可选 `cmd/accountsvc` 装配库运行，提供 SMTP、阿里云短信、JWKS、内省、已清理用户拉取、服务认证、管理员 OIDC、探针和优雅关闭；库不依赖该进程。服务环境变量前缀为 `ACCOUNTSVC_`，不提供产品网关或内置管理员账号系统。
- 验证工具采用 sqlc 1.31.1 和 PostgreSQL 17 客户端；运行库无需安装 sqlc。当前仓库未提供开源 LICENSE，不因本次发布新增外部复用许可。

安装：

```bash
GOWORK=off go get github.com/bbxx111/accountkit@v1.0.0
```

## 开发期调用切换与正式契约

v0.1.0–v0.7.2 为未正式使用的开发期版本。按用户确认，本次已先完成 v1.0.0 发布与远端消费，再删除九个 v0 tag 和现存八个对应 GitHub Release；开发期摘要及完整提交 SHA 留存于[开发期历史](https://github.com/bbxx111/accountkit/blob/v1.0.0/docs/releases/pre-1.0-history.md)。本说明提供 Go 调用替换指引，不提供开发期数据库原地升级路径。

- 验证码接口采用 `SMSCodeSender`、`EmailCodeSender`、`CodeMessage`；流程采用 `SignInCompletionFlow`、`SignInCompletionFlowContext`、`CleanupSignInCompletionFlows`，旧别名已移除。
- 微信构造器采用 `NewWeChat(WeChatConfig, *http.Client, *slog.Logger) (*WeChat, error)`；SMTP 渲染器为 `ChineseRenderer`；grace.Pair 字段为 `AccessExpireTime/RefreshExpireTime`，缓存 JSON `ae/re` 保持。
- `user.PurgeCoveredTables()` 返回独立 map；移除无用的公开旧审计转换/查询和内部批量/错误符号。保留私有旧审计快照读取，不承诺旧库转换。
- 保留不透明 `user.Repo/NewRepo`、直接领域装配和密钥检查；原始 `Q/WithTx/WithTxRaw` 私有化。sqlc 与 HTTP helper 内部化，不再允许外部依赖旧包。联合事务使用公开领域操作及宿主回调中的同一 `pgx.Tx`。

逐符号替换及其他接受的 API 边界以[兼容指南](https://github.com/bbxx111/accountkit/blob/v1.0.0/docs/compatibility.md#v100-调用者须知)为准。公开 Go API 自 v1.0.0 起受语义化版本约束，后续破坏性变化须新主版本及 `/v2` 模块路径。

## 数据库与回退

新空 schema 从唯一生产迁移 `0001` 安装为 version=1、dirty=false。默认 schema 为 `account`，实例隔离由宿主明确配置。当前初始定义自 v1.0.0 tag 起字节冻结，后续真实结构变更从 0002 递增；本发布不修改 SQL。

| 文件 | SHA256 |
|---|---|
| `0001_init.up.sql` | `ef2d1f229fa15b660cc7ecb4f417615b76866c19494641c96faf25bab24188b6` |
| `0001_init.down.sql` | `812541721471025056edd1f655d876b2f4d938fffd8f4f7ee2cfa9a97ff490d5` |

迁移预检保留 dirty 优先阻断及数据库版本超出当前源时拒绝，不反查开发期旧结构，不自动 Force/清 dirty。公开 Down 无 I/O 返回 `ErrDestructiveOperation`；UnsafeReset 仅用于精确确认的一次性开发测试 schema。

本版本没有此前正式版可供回退，不支持切回 v0 结构。未来回退须先验证新结构兼容旧应用；数据库恢复先在独立空库验证，明确备份时间以来的数据损失窗口。备份不包含 Redis 和密钥系统，清空 Redis 不构成安全恢复；缺陷应前向修复，已发布 tag 不移动。操作细节见[迁移手册](https://github.com/bbxx111/accountkit/blob/v1.0.0/docs/migrations.md)。

## 验证与未验证边界

准备快照已通过生成代码/迁移历史/OpenSpec/OpenAPI 校验、Linux build/vet/race、981 项库与 62 项 accountsvc 必需门禁、真实 pg_dump/pg_restore 三阶段和非 root 权限补验。最终 main 候选的在线 CI head_sha 精确匹配并全部成功；tag 发布后两个 GOWORK=off、无本地 replace 的独立宿主均已从远端 go get v1.0.0，编译根门面与直接 HTTP 适配器，模块版本及两个初始 SQL 哈希一致。

隔离测试不等于产品上线验收。微信/Apple 真实应用、SMTP 最终投递及邮件客户端显示、阿里云短信真实签名/模板、服务 Bearer 内省的真实 IdP 链路、管理面 no-store 的其他网关透传、production HTTPS 管理员 OIDC 仍由集成方按启用能力验收；开发期已有联调不冒称 v1.0.0 已复验。Windows 权限语义未验证。平台特定客户端 SDK、纯第三方账号自助恢复、更多认证方式和账号合并不在本版本承诺内。

发布过程与测试证据统一记录在[本次验收记录](https://github.com/bbxx111/accountkit/blob/develop/openspec/changes/prepare-v1-0-0-release/verification.md)。产品侧仍需完成[上线检查表](https://github.com/bbxx111/accountkit/blob/v1.0.0/docs/release-checklist.md)中的网关、秘密、匿名化、监控、升级和灾备责任。
