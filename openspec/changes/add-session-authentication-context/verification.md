## 已确认范围

- 当前会话采用方案二：服务端详情接口返回具体认证身份及类型，不向 JWT 添加来源字段。

- 身份解绑撤销命中来源及来源未知的同账号会话；用户已明确确认未知旧会话同时撤销，升级本身不强制退出。
- 客户端描述可选，登录、重新认证、新一轮刷新采集；普通业务鉴权不增加数据库热路径。

本轮为顺序自查，未启动并行代理或声称已完成独立代码审查。已逐项核对协议、来源语义、历史兼容及数据生命周期：
