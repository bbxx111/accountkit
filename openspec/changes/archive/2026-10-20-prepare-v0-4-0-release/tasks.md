- [x] 1.1 盘点 v0.3.0 之后的最终变更及相关规格，确认下一版本为 v0.4.0。
- [x] 1.2 编写发布说明及版本门禁，明确旧库拒绝、会话来源撤销、直接 Go 解绑迁移、连接池容量、客户端描述、开发中字段删除与集成方责任。
