# Spec Delta

## MODIFIED Requirements

### Requirement: 内置头像资料
账号 SHALL 保存可选 avatar_url；未设置以数据库 NULL 表示，Go 和 HTTP 读取返回空字符串。本人资料、管理列表及详情 SHALL 返回该字段。头像 SHALL 独立于可选 profile_attributes Schema，扩展顶层不得重复声明 avatar_url。头像文件上传、存储、默认头像和第三方头像的持续同步由宿主负责。其他规格规定的一次性填充以及支付宝后续成功登录的空字段补填，可以把已通过地址校验的 URL 写入仍为空的 avatar_url；库 SHALL 不访问该地址。

#### Scenario: 新账号和已设置头像
- **WHEN** 读取新账号或已设置头像的账号
- **THEN** avatar_url 分别为空字符串或已保存的地址，不增加 JWT 或内省字段

#### Scenario: 一次性填充不转移文件责任
- **WHEN** 其他规格把通过地址校验的 URL 写入仍为空的 avatar_url
- **THEN** 读取返回该地址，库不访问它；宿主继续负责文件、默认头像和此后的同步

#### Scenario: 支付宝补填头像
- **WHEN** 支付宝后续登录取得可信且合法的头像 URL，写入时账号头像仍为空
- **THEN** 可以保存该 URL，不下载图片，不对非空头像做持续同步

## ADDED Requirements

### Requirement: 支付宝登录按字段补填空资料
ALIPAY 首次及后续成功登录 SHALL 使用本次可信并净化后的 nick_name/avatar 声明分别填充仍为空的 display_name/avatar_url，不覆盖任一非空字段。空值 SHALL 按现有 NULL 或空字符串表示判断；用户主动清空也属于可补填空值，不新增自动补填开关或来源标记。资料缺失或无效时 SHALL 保持对应字段和既有元数据，不使用历史元数据替代本次失败的资料结果。

#### Scenario: 首次失败后成功
- **WHEN** 首次支付宝登录资料接口失败但身份登录成功，后续登录取得有效昵称及头像
- **THEN** 在后续登录提交时补填仍为空的字段，既有用户 ID 和支付宝身份 ID 不变

#### Scenario: 已有昵称只有头像为空
- **WHEN** 登录取得昵称与头像，而账号显示名已经非空
- **THEN** 仅补填头像，不将支付宝昵称覆盖到账号显示名

#### Scenario: 主动清空后的登录
- **WHEN** 用户主动清空头像，之后一次支付宝登录取得合法头像
- **THEN** 按空字段规则补填，文档明确主动清空不表示永久关闭提供方补填

#### Scenario: 资料失败不使用旧缓存
- **WHEN** 本次资料查询失败，身份元数据中有历史 profile，而账号资料为空
- **THEN** 本次不使用历史 profile 自动回填，允许登录并等待下一次取得可信资料

### Requirement: 支付宝资料补填的原子性
资料补填 SHALL 与相应账号、身份及会话操作处于同一领域事务，在写入时按既有账号锁序复核 ACTIVE 状态与每个字段是否仍为空。失败、身份冲突、账号生命周期拒绝或事务回滚 SHALL 不留下补填结果。pending 完成 SHALL 只使用已保存的净化声明，不重新访问支付宝；仅创建 pending 不得改写任何账号资料。

#### Scenario: 用户并发设置资料
- **WHEN** 登录取得资料后，用户的 PATCH 已先提交非空昵称或头像
- **THEN** 登录写入时重新检查字段，保留用户已提交的值，不使用查询前快照覆盖

#### Scenario: 冻结或注销竞争
- **WHEN** 验证身份后账号变为 FROZEN、PENDING_DELETION 或 DELETED
- **THEN** 按既有账号状态规则拒绝对应操作，未提交的资料补填回滚，不在匿名化后补回资料

#### Scenario: pending 关联到已有账号
- **WHEN** 首次支付宝登录进入 pending，完成时关联到已有 ACTIVE 账号
- **THEN** 在完成事务内仅填充目标账号的空字段，保留并发或此前设置的非空资料

#### Scenario: pending 并发取得同一身份
- **WHEN** pending 创建后同一支付宝身份已由另一成功流程关联到最终目标账号
- **THEN** 完成流程按原冲突与幂等规则复核归属，仅在允许完成的事务中执行空字段补填

#### Scenario: 登录最后阶段失败
- **WHEN** 补填后创建会话或保存客户端信息失败并回滚
- **THEN** 账号资料、身份元数据及会话保持事务前状态
