# Proposal

## Why

本批功能已归档并合入develop，基线CI通过，但尚缺正式发布的版本兼容决策、候选说明及最终候选验证证据。必须区分Go公开源码、accountsvc部署契约和已独立发布的SDK版本，避免以测试通过代替版本承诺。

## What Changes

- 对照正式v1.0.0盘点新增能力和真实破坏性变化，明确未发布实施过程中的改名不属于正式版本升级项。
- 修正兼容指南与服务手册的过时摘要，整理配置、主体、scope、错误、readiness及回退要求。
- 经用户确认版本策略后编写一致的候选发布文档与核验计划；最终main候选须有精确SHA对应的线上证据。
- 当前范围仅为文档准备和核验，skip_specs为true；若选择Go新主版本，模块路径迁移须补充明确的规格及实施范围后再执行，不能据本提案静默修改代码。
- 本轮不执行tag、GitHub Release、main集成或产品部署。

## Capabilities

### New Capabilities

无。发布准备不新增运行能力。

### Modified Capabilities

当前无运行契约变更；只准确说明已实现并归档的行为。版本策略尚待确认，不预先声明新的模块身份或服务版本承诺。

## Impact

影响发布说明、兼容与服务接入文档及本变更验收记录。Go module/import、数据库、依赖和SDK版本保持到版本策略被明确选择；不改历史正式tag或Release。设计与任务在版本决策后按确定范围展开。
