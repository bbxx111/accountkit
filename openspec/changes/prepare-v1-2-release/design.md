# Design

## Context

见[提案](proposal.md)。正式基线v1.1.0为6eef5e3，当前develop为aa434ed，main仍为上一版发布补记。两项功能变更已归档，当前45份主规格已同步；用户指定本次发布v1.2.0。长期发布步骤以[发布检查表](../../../docs/release-checklist.md)为准。

## Goals / Non-Goals

**Goals:** 固定准备快照、最终main候选、正式tag及消费证据之间的关系；让升级者准确了解管理员授权迁移；完整执行用户已授权的发布链路。

**Non-Goals:** 不恢复内置管理角色，不更改运行行为、依赖、SQL、密文或令牌格式；不发布新SDK，不拆出服务版本轴，不把模拟提供方当作产品验收，也不自动归档发布准备变更。

## Decisions

### 1. 本次版本与兼容范围

按用户明确指定发布v1.2.0，保持github.com/bbxx111/accountkit及全部既有导入路径。公开Go接口加法兼容；accountsvc与库同源交付，管理员授权从内置角色改为显式映射属于部署破坏性迁移，必须在发布说明、兼容和服务手册显式标注。此选择不称作服务全面向后兼容，也不泛化为未来可以任意破坏v1契约。

### 2. 候选与发布后状态

准备材料统一标注v1.2.0（候选），三份OpenAPI info.version使用v1.2.0；SDK仍为1.0.0。发布说明预先给出可预知Release链接，最终tag包含候选说明。正式tag/Release及两个远端Go消费通过后，再以补记提交改成已发布并写入精确对象；不为更新状态而移动tag。

### 3. 验证与实例隔离

准备快照使用任务专用PostgreSQL17/Redis和Linux验证容器，将源码及完整Git历史复制到容器本地文件系统，保留原超时/race/必需测试/恢复门禁。源库和恢复目标均为不同的一次性空库，只清理本任务完整ID及标签匹配的资源。

SDK精确工具来自tool-versions.json；本地逻辑/真实服务/固定Git消费及在线Android/iOS结果分别记录。兼容矩阵先pending，只有实际服务/SDK门禁通过后才标verified；发布Go版本不授权SDK新tag。Windows不能代替macOS门禁，最终在线SDK workflow必须实际通过iOS任务。

### 4. 集成与最终候选

发布准备在短期分支分阶段提交，按默认PR合入develop，再用独立merge commit合入main。冻结最终main候选后，等待该SHA的Go与SDK完整在线检查全部成功，核对同名tag不存在，再创建annotated tag及Release。此前成功的其他SHA不代替最终候选。

### 5. 正式消费与补记

tag推送后才可能验证正式Go模块；两个新临时宿主分别消费根门面和直接HTTP适配器，同时覆盖旧角色接口与新权限接口，GOWORK=off且无replace，核对go list版本、公开符号及冻结初始迁移哈希。失败时保留tag和事实，修复走新提交/版本，不覆盖正式tag。

成功后更新发布状态、兼容登记和verification，补记分支按相同merge commit规则集成develop/main；tag仍固定原受测候选。每阶段只运行适合其变化的检查，历史记录与新候选结果明确区分。

## Risks / Trade-offs

- 管理部署被误当作无迁移升级 → 明确空策略403、精确角色映射、全部副本重启/排空和旧二进制回退扩权风险。
- tag包含未经验证提交 → 最终main SHA与在线Go/SDK结论逐项匹配；tag前不再修改候选。
- 本地恢复覆盖既有数据 → 全新专用数据库、完整资源ID/标签和源目标非同一检查，保留备份及原始输出于忽略目录。
- SDK版本与服务版本混淆 → 两SDK保持1.0.0，仅新增服务v1.2.0兼容证据；不创建SDKtag。
- 近似工具或skip冒充通过 → 精确版本、实际平台构建与条件skip补验分别记录，缺门禁不发布。

## Migration Plan

升级前保存v1.1.0二进制、提供方角色签发和配置，显式配置ADMIN_ROLE_BINDINGS及各别名NAME/PERMISSIONS；按实际职责枚举权限或明确接受资源组通配符未来扩权。无映射时有效管理员403，scope不能补救；相同有效JWT角色可继续使用。更新全部副本或排空旧副本，核对11个管理操作及401/403/503边界。

回退同步恢复旧二进制与匹配配置，重新核验其内置operator/super-admin权限可能扩大授权；本批没有数据库结构升级，不清库、不清Redis、不Force。真实OIDC/发送器、产品网关与部署验收不由本次库发布替代。
